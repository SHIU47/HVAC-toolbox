# 審核範圍

- **審核對象**：`public/index.html` 的公開首頁（Landing Page）；`dist/index.html` 為已建置輸出，未作為修改建議的主要來源。
- **主要使用者**：台灣的 HVAC／MEP 工程師、設計人員與現場技術人員。
- **主要任務**：首次訪客理解工具價值，並自信地點選「開始系統計算／進入工具箱」開始使用合適的工程工具。
- **已知技術限制**：單一 HTML 檔、Tailwind CDN、外部 Font Awesome、Google Fonts、Clerk 與 Firebase；目前未發現可安全啟動且不會自動開啟外部瀏覽器的首頁預覽流程。
- **品牌與體驗目標**：從「特效豐富的工程 Demo」提升為「可信、克制、有精密感的專業工程產品」。
- **參考輸入**：使用者要求首頁更精緻、高級，並希望首次進站具有驚豔感；未提供競品或視覺參考。

## 審核方法

依 Dieter Rams 的十項好設計原則檢視目前已實作的首頁。所有結論以 `public/index.html` 的程式碼可驗證事實為基礎；未對可執行畫面做像素級或網路瀑布圖量測之處會明確標為推估。
