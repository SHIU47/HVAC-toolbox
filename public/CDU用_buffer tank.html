      計算假設與工程模型限制

      為什麼 CDU 二次側必須使用「強制混合型緩衝槽（Mixing Tank）」而非冰水側的「分層型緩衝槽（Stratified Tank）」？

      冰水側（FWS）停電緩衝槽追求的是斜溫層（Thermocline Stratification），利用低速布水器維持穩定出水溫度直到冷水流盡；但 CDU 二次側（TCS）緩衝槽的任務是「熱脈衝削峰（Thermal Peak Shaving）」。當 GPU 在 1 秒內拉升至 100% 滿載時，CDU 出口會湧出高達 47°C 的熱脈衝。若採用分層槽，熱水會直接平推穿透或浮在頂部流向機櫃造成超溫跳機；因此必須採用內置文丘里多孔噴射混流管（Venturi Jet Sparger）與交錯折流擋板（Segmental Baffles）的強制湍流混合槽，將湧入的高溫液體瞬間與槽內 40°C 儲液均勻攙混，把供水峰值壓制在 45°C 以內。

      單一分段線性精確暫態求解器

      負載與 CDU 冷量皆為分段線性函數，求解器自動找出所有斜率轉折點與交叉點（Knots）切段後精確解析積分，求得：最大瞬時缺口、最大累積儲熱能量 E = max ∫(Q負載 − Q冷量)dt、峰值溫度時間與二次方程精確熱恢復時間。網頁圖表、3D 模擬器、計算步驟與匯出的 Excel 均共用同一組求解器結果。

      Model A：閉迴路累積儲熱（Closed-Loop Cumulative Integral，預設選型基準）

      控制方程為 ρ·cp·V有效·dT/dt = Q負載 − Q冷量。在閉迴路中，回水 = 槽溫 + Q負載/(ṁcp)，CDU 出口 = 槽溫 + (Q負載 − Q冷量)/(ṁcp)，代入混合槽一階方程後流量項互相抵消，即得此式——所以在「CDU 冷量為給定時間函數」的前提下，Model A 就是串聯混合槽的正確閉迴路解，而非過度保守的近似。其保守性來自：把全部缺口熱量只放進水槽（忽略槽體金屬、管路、熱交換器、歧管與冷板之額外熱容量），且忽略一次側熱交換器隨入口水溫升高而自然增加的換熱量（LMTD 自調節）。

      Model B：一階 CSTR 對流混合（單次通過，非保守下限）

      τ·dT槽/dt + T槽 = T設計 + max(0, Q負載 − Q冷量)/(ṁ·cp)，τ = V有效 ÷ V̇事件。在每個分段線性區間以積分因子精確解析求解。此模型假設流回 CDU 的回水溫度不受槽溫上升影響（等同迴路循環時間無限長／單次通過），因此必然 ≤ Model A，且在大容積時收斂到 Model A。只有當 TCS 迴路循環時間（迴路容積 ÷ 流量）明顯長於 Model B 峰值時間時才接近真實；否則會低估峰值與容積。Model B 適合用來理解削峰機制與敏感度，正式選型建議以 Model A 為準。

      二次側水泵流量模式

      定頻：事件期間 100% 額定流量。變頻：保守假設泵在事件期間尚未爬升，流量 = max(最低流量下限, 跳升前負載%) × 額定流量。流量只影響 CDU 出口脈衝溫度（無水槽第一圈估算）與 Model B 的時間常數；Model A 屬能量守恆，不受流量影響。本工具屬於概念設計／初步容量估算，非 CFD 或完整迴路暫態模擬。

      穩態容量 vs 水槽熱恢復時間

      若「CDU 最大可用冷量」剛好等於「跳升後負載」（例如皆為 100%），當冷量追上負載後淨缺口為 0，水槽不再升溫但也沒有多餘冷量將已累積的熱量排掉，溫度將維持在峰值（熱恢復時間為無限大）。若要評估熱恢復時間，請依一次側實際最大供冷能力將「最大可用冷量」設為高於跳升後負載（例如 105%～120%）。
